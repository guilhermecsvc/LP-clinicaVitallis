# Landing page – Clínica Vitallis

Landing page da **Clínica Vitallis – Saúde Mental Integrada** (Alameda Shopping, Taguatinga Sul – DF).

- Arquivo único: `index.html` (HTML, CSS e JavaScript juntos; imagens já incorporadas).
- Agendamento via WhatsApp (formulário em 3 etapas), busca de convênios, mapa e FAQ.
- Eventos de clique enviados ao `dataLayer` (Google Tag Manager / GA4).
- Respeita a preferência "reduzir movimento" do sistema.

## Publicar com GitHub Pages
Settings → Pages → *Deploy from a branch* → `main` / `(root)`.

## Antes de publicar
- Trocar `SEU-DOMINIO.com.br` nas meta tags (canonical e og).
- Conferir horários e lista de convênios com a clínica.
